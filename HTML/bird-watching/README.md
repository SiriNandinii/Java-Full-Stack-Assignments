# 🐦 Birdwatching Website

*A cozy little corner of the internet for bird lovers.*

---

## 🌿 About the Project

Welcome to the **Birdwatching Website** — a warm, simple, and responsive static site built with just **HTML5** and **CSS3**. Designed as a homepage for a fictional birdwatching community, it's a little digital nest where nature-lovers can gather, admire feathered friends, and soak in some calm, earthy design.

No frameworks, no JavaScript — just clean code and a love for good design.

---

## ✨ Features

### 🏡 Header
A soft gradient welcome with a bird-themed logo and centered title — like stepping onto a porch on a quiet morning.

### 🍃 Navigation
A dark green, nature-inspired menu with gentle hover animations:
`Home` · `Get Started` · `Photos` · `Gear` · `Forum`

### 📖 Welcome Section
A warm introduction to the birdwatching community, written with clean semantic structure and comfy spacing.

### 🖼️ Photo Gallery
A grid of rounded, shadowed bird photos with a gentle hover-zoom — like flipping through a favorite field journal.

### 🌙 Footer
A simple, minimal dark green footer to close things out.
