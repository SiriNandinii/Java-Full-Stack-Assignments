## 🌟 About the Project

**TechNova** is a responsive company profile website built with **HTML5** and **CSS3**. It's a polished business landing page — complete with a nav bar, hero section, company overview, services, and a contact call-to-action — designed to feel great on desktop, tablet, and mobile alike.

---

## ✨ Features

- 🧭 Responsive navigation bar
- 🎯 Eye-catching hero section
- 🏢 About Us section
- 🗂️ Feature cards
- 🛠️ Services section
- 📞 Contact call-to-action
- 🦶 Professional footer
- 📱 Fully responsive design
- 💫 Modern UI with hover effects
- 🧼 Clean, semantic HTML structure

---

## 🧵 Built With

**Languages:** HTML5, CSS3
**Fonts & Icons:** Google Fonts (Poppins), Font Awesome
**Techniques:** Flexbox · CSS Grid · Media Queries · Hover Transitions

## 🚀 How to Run

1. Download or clone the repository.
2. Open the project folder.
3. Double-click `index.html`, or open it in any modern browser.
4. Make sure the `images` folder stays in place so everything loads properly.
