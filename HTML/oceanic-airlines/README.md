## 🌊 About the Project

**Oceanic Airlines** is a static homepage mockup for a fictional airline, built with just **HTML5** and **CSS3**. It's a cozy little dive into semantic markup and responsive design — capturing that easy, breezy feeling of ocean travel through clean layouts and a calm, blue color palette.

No frameworks, no JavaScript — just thoughtful structure and a love for good design.

---

## ✨ Features

- 🧭 Animated navigation bar with rounded tabs & arrow indicators
- 🌅 Hero banner showcasing a dreamy travel destination
- 👋 Warm welcome section introducing the airline
- 🗂️ Info cards for travel resources
- 🎨 Ocean-and-travel-inspired color palette
- 🪶 Textured page background
- ⌨️ Keyboard-accessible navigation with focus styles
- 💫 Smooth hover animations & transitions
- 🌍 Cross-browser compatible design
