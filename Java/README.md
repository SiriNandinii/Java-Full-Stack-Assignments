### 🚛 OOPS2 — *toll booth management system*
a full lil project simulating a real toll booth, all wrapped up in oop goodness 🎟️

**what's inside:**
- 🚚 truck interface
- 🚧 toll booth interface
- 🛻 multiple truck implementations
- 💰 toll calculation
- 🧾 receipt management
- 🔄 collection reset functionality
- 🎬 main driver class

**oop concepts covered:** interfaces, abstraction, encapsulation, polymorphism, interface implementation, and object interaction 🌈

trucks get charged based on axles & weight, receipts get tracked, and everything stays cozy and organized behind the scenes 🚦

---

### 🧺 Collections — *java's little storage baskets*
practical programs to explore the java collections framework 🗃️

**ArrayList operations:** create, insert, retrieve, update, delete, search, sort, copy, shuffle, reverse, extract sublists, replace elements 📋

**HashSet operations:** union 🤝, intersection 🔗, difference ➖

**HashMap operations:** storing employee objects 🧑‍💼, retrieving by id 🔍

**important concepts:** dynamic & generic collections, searching, sorting, set operations, key-value mapping, and storing objects neatly 🧸

---

### 🍋 Java8 — *functional programming, but make it fun*
all about java 8's newer, shinier features ✨

**stream api:** filter even numbers, numbers starting with 1, count elements, sort collections, max/min values, sum, average 🌊

**lambda expressions:** odd number checker, prime number checker, palindrome checker λ

**movie rating system:** filter movies 🎬, sort movies, group by genre 🎭, find the highest rated movie ⭐

**method references:** display collections, sorting, uppercase conversion 🔠

**date & time api:** current date 📅, month, day of week, days between dates, leap year check 🍃

**functional interfaces:** uppercase/lowercase conversion, reverse string, string length 🧶

**concepts covered:** lambda expressions, functional interfaces, stream api, method references, LocalDate api, functional programming, and collection processing 🌼
